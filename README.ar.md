# Prism Desk · 棱镜

<img src="src/assets/prism-icon.svg" width="80" height="80" alt="Prism Desk">

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [العربية](README.ar.md)

من إنشاء [Shixi Lin](https://shixilin.com/).

Prism Desk هو مساحة عمل على Windows لواجهات CLI التي تعمل بالاشتراك. عندما تنفد حصة الاستخدام في أحد الحسابات، يمكنك نقل المهمة إلى حساب آخر دون إعادة تجميع محادثتها وملاحظات تقدمها يدويًا. ويظل مجلد المشروع كما هو.

### الإصدارات والتنزيلات

**[أحدث إصدار](https://github.com/shixi-11/prism-desk/releases/latest)** · **[دليل التثبيت](#install)**

يتوفر Prism حاليًا عبر **التثبيت من الشفرة المصدرية على Windows**. لا يتوفر برنامج تثبيت مستقل بصيغة `.exe` أو `.msi`. تحتوي تنزيلات «Source code» في GitHub على ملفات الشفرة المصدرية؛ اتبع دليل التثبيت لبناء تطبيق سطح المكتب وتشغيله. لكل إصدار مستقر وسم إصدار واحد وصفحة واحدة تتضمن ملاحظات التغييرات كاملة بالإنجليزية والصينية المبسطة.

### التثبيت

تثبّت هذه الأوامر الإصدار المستقر **v0.1.6**. راجع [أحدث إصدار](https://github.com/shixi-11/prism-desk/releases/latest) لمعرفة رقمه وملاحظات تغييراته باللغتين.

ستحتاج إلى Windows وGit وNode.js 22.12 أو أحدث وnpm، بالإضافة إلى واجهات CLI الرسمية للمزوّدين الذين تختارهم. سجّل الدخول إلى كل CLI على حدة.

```powershell
git clone --branch v0.1.6 https://github.com/shixi-11/prism-desk.git
cd prism-desk
npm install
npm run build
npm run build:desktop
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-host.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1
```

يُجمّع برنامج البناء النصي مضيف عمليات Windows المستخدم لإيقاف العمليات الفرعية لـ CLI معًا. ويستخدم مُصرِّف .NET Framework المضمّن مع Windows.

### قبل مهمتك الأولى

ثبّت CLI الرسمي لكل مزوّد تريد استخدامه، ثم سجّل الدخول من خلاله. تسجيل الدخول إلى موقع ويب أو تطبيق سطح مكتب وحده لا يُعِدّ Prism.

- **Codex:** اتبع [دليل تثبيت CLI](https://developers.openai.com/codex/cli/) وسجّل الدخول بحساب ChatGPT الخاص بك.
- **Claude:** ثبّت [Claude Code](https://code.claude.com/docs/en/setup)، ثم [سجّل الدخول](https://code.claude.com/docs/en/authentication) باستخدام اشتراك Claude مدعوم. يتحقق Prism من تسجيل الدخول بالاشتراك وإعدادات الاستخدام الإضافي قبل التنفيذ؛ ويجب تعطيل الاستخدام الإضافي.
- **Grok:** ثبّت Grok CLI الرسمي وسجّل الدخول إليه بحساب اشتراكك.

افتح **الحسابات → ربط حساب**، واختر Codex أو Claude أو Grok، وسمِّ الحساب. يبدأ **حفظ ومتابعة → الحصول على رابط تسجيل الدخول → نسخ رابط تسجيل الدخول** مسار التفويض الرسمي لـ CLI. الصق الرابط في شريط العنوان في متصفحك. إذا عرض Claude رمز تفويض، فالصق الرمز كاملًا في **رمز التفويض** واختر **إرسال الرمز**. يُرسل الرمز إلى CLI الرسمي المنتظر فقط، ثم يُمسح من حقل الإدخال. بعد منح التفويض، يتحقق Prism من تسجيل الدخول بالاشتراك ويتيح الحساب للاستخدام دون إعادة تشغيل. تدعم الصفحة أيضًا التحقق من تسجيل دخول موجود، وإلغاء التفويض أو نسخ الرابط مجددًا، وإعادة تسمية ملفات التعريف، وتعطيل الحسابات أو تفعيلها. يحتفظ التعطيل بالمهام السابقة وبيانات الاعتماد. تتيح لك الإعدادات المتقدمة اختيار الملف التنفيذي الرسمي لـ CLI أو استيراد دليل تسجيل دخول مستقل موجود؛ ولا يمكن تغيير أدلة الحسابات وهويات المنصات التي سبق إعدادها. عند غياب CLI، تتوفر روابط إلى تعليمات التثبيت الرسمية. تحتاج المنصات التي تُضاف مستقبلًا إلى موائمات خاصة بها للمزوّد وللتنفيذ.

### سير مهمة اعتيادية

1. انقر على **مهمة جديدة** وسمِّها. مجلد المشروع اختياري؛ وتركه فارغًا ينشئ مساحة عمل مستقلة ودائمة للمهمة.
2. اختر حساب التنفيذ والنموذج ومستوى جهد الاستدلال. استخدم **للقراءة فقط** للمراجعة، أو **تعديل المشروع** للتحرير.
3. أدخل طلبك وأرسله باستخدام **Ctrl + Enter**. تابع المحادثة وسجل التنفيذ مع تقدم العمل.
4. أضف القرارات المهمة أو العمل المتبقي إلى ملاحظات التقدم. لتغيير الحساب، اختر الحساب التالي واستخدم أداة التسليم؛ وأوقف التنفيذ الحالي أولًا عندما يلزم ذلك.
5. أعد تسمية المهمة باستخدام زر القلم الخاص بها، أو بالنقر المزدوج، أو باستخدام **F2**. اضغط **Enter** للحفظ أو **Esc** للإلغاء.
6. واصل العمل في المهمة نفسها. صدّر سجلها عندما تحتاج إلى نسخة Markdown، أو افتح مجلد تخزين المهام للوصول إلى الملفات المحلية.

يتلقى الحساب التالي المحادثة المحفوظة وملاحظات التقدم وسجلات الأدوات. لا تُنقل الحالة الداخلية للنموذج لدى المزوّد.

### الرسائل والإعدادات والمعاينات

#### الأهداف والخطط

يعرض **شريط الهدف** الموجز فوق محرر الرسائل الهدف المحفوظ وحالة التنفيذ ووقت التنفيذ المتراكم. يمكنك تعديل الهدف أو إيقافه مؤقتًا أو استئنافه أو حذفه من الشريط؛ ويمكنك توسيعه لعرض الهدف كاملًا والخطة القابلة للتعديل وتفاصيل التنفيذ. يوقف الإيقاف المؤقت التنفيذ الحالي ويعلّق الرسائل الموجودة في قائمة الانتظار. ينتظر الحذف توقف التنفيذ، ثم يزيل الهدف ويُبقي الرسائل المعلّقة للمراجعة؛ وتظل سجلات المحادثة وملفات مساحة العمل متاحة. يستبعد المؤقت فترات الإيقاف المؤقت والخمول والوقت الذي يكون فيه التطبيق مغلقًا. يُعرض نفاد الحصة الرسمية بشكل منفصل عن أعطال الشبكة أو تسجيل الدخول.

يمكن لـ Codex حفظ الأهداف عبر أدوات Prism الأصلية عندما تطلب منه تحديد هدف أو تغييره. ويمكن لمداخل التشغيل الأخرى اقتراح هدف لتتبناه من خلال الواجهة. نص المحادثة الذي يدّعي حفظ هدف لا يغيّر الهدف الفعلي بمفرده مطلقًا. يعمل **وضع خطة أولاً** بصلاحيات القراءة فقط ويعيد مسودة للمراجعة. يوضح محرر الرسائل صراحةً متى تقتصر الرسائل على مناقشة خطة بانتظار التأكيد؛ ويبدأ **تأكيد الخطة وتنفيذها** التطبيق الفعلي بالصلاحيات المحددة للمهمة. تستمر الأهداف والخطط عبر الجلسات وتبقى في سجل التسليم.

#### النماذج والتسليم

يمكن تطبيق تغييرات النموذج ضمن الحساب نفسه باستخدام **تبديل ومتابعة**. يسجل التنفيذ المؤكد حسابه ونموذجه ومستوى استدلاله؛ ولا يُعرض مجرد حفظ الاختيار على أنه تبديل مكتمل. يفتح **تفضيلات المتابعة التلقائية** قائمة حسابات يمكنك سحب عناصرها لإعادة ترتيبها، مع إعدادات للنموذج ومستوى الاستدلال لكل حساب. تُحفظ التغييرات تلقائيًا للمهمة الحالية. تميّز القائمة الحسابات التي لا تلبي متطلبات صلاحية الكتابة للمهمة؛ ويراعي التسليم أيضًا دعم الصور.

#### الحسابات والنوافذ

تحتوي كل بطاقة حساب على **الاسم المستعار** قابل للتعديل باستخدام زر القلم. يغيّر ذلك اسم العرض، ولا يغيّر هوية تسجيل الدخول. توفر أسئلة Codex الأصلية والرسائل المدعومة بصيغة سؤال وقائمة خيارات اختيارات قابلة للنقر وإجابة مخصصة. يؤدي النقر على **×** في شريط عنوان Windows إلى إخفاء Prism في منطقة الإعلام؛ استخدم **إنهاء Prism** من قائمة علبة النظام لإيقاف العمل النشط والخروج.

#### تنظيم المهام

انقر بزر الفأرة الأيمن على مهمة لإعادة تسميتها، أو تثبيتها، أو وضع علامة غير مقروءة عليها، أو أرشفتها، أو تجميعها حسب المشروع أو القسم، أو مشاركتها، أو نسخها، أو إنشاء فرع منها، أو فتح مجلدها أو محادثتها، أو فتح نافذة أخرى، أو حذفها. يتيح **المؤرشفة والمحذوفة** في الشريط الجانبي استعادة المهام المخفية. يحتفظ حذف المهمة بمساحة عملها وملفات محادثتها. يغيّر اختيار المشروع مكان تنفيذ العمل اللاحق؛ وتبقى الملفات الموجودة في مجلدها الأصلي. يبدأ إنشاء فرع جلسات CLI جديدة وينسخ مرفقات المحادثة؛ ويبدأ خيار مساحة العمل المستقلة بمجلد فارغ. تعرض المشاركة معاينة لمستند Markdown محلي لنسخه أو حفظه؛ ولا تنشئ رابطًا عامًا مستضافًا. تتزامن تغييرات المهام بين النوافذ المفتوحة.

#### العرض وحصة الاستخدام

يحتوي الشريط العلوي على إعدادات العرض ومفاتيح إظهار وإخفاء سجل التنفيذ السفلي والشريط الجانبي للحسابات. تُحفظ حالتها محليًا. في الحسابات، يستعلم **فحص جميع الحسابات** عن كل ملف تعريف مُعدّ ويعرض الحصة المتاحة ومواعيد إعادة التعيين وأرصدة إعادة التعيين في Codex وتواريخ انتهاء صلاحية الأرصدة. لا يوقف فشل أحد الاستعلامات فحص الحسابات المتبقية.

#### الصور

الصق لقطات الشاشة، أو أسقط الصور في محرر الرسائل، أو استخدم زر الصور، بحد أقصى خمس صور وحجم 10 MB لكل صورة. يتلقى Codex صورًا محلية؛ ويتلقى Claude محتوى الصور عبر دعم الصور المدمج عند اجتياز فحوص الاشتراك. لم يُتحقق بعد من تنفيذ Claude باستخدام الصور على حساب مسجّل الدخول. يستخدم Grok محتوى الصور مباشرةً عندما يعلن CLI دعمه لذلك، وإلا فتفتح أداة Read المضمنة الصور المرفقة؛ وقد جرى التحقق من هذا المسار باستخدام اشتراك مسجّل الدخول.

#### الرسائل والمسودات

يمكنك إرسال مزيد من الرسائل أثناء تنفيذ العمل: تنتظر بالترتيب ويمكن إلغاؤها. تتيح لك الإعدادات اختيار Enter أو Ctrl/⌘+Enter للإرسال، واختيار قائمة الانتظار أو التوجيه المباشر. يستخدم التوجيه المباشر دور Codex النشط؛ أما المزوّدون الآخرون فيعودون إلى قائمة الانتظار. يؤدي فشل الإرسال أو انقطاعه إلى تعليق الرسائل اللاحقة للمراجعة. تُحفظ المسودات عند التبديل بين المهام ما دام التطبيق مفتوحًا.

#### معاينات الملفات

افتح لوحة المعاينة أو انقر على رابط ملف لعرض الصور وملفات PDF وMarkdown والشفرة والنصوص. يمكن تعديل الملفات النصية وحفظها؛ ويُتحقق من التغييرات الخارجية قبل الحفظ. تعرض معاينات HTML صفحات مستقلة؛ ويمكن للمشروعات التفاعلية استخدام عنوان HTTP الذي تعمل عليه. تحظر بعض المواقع التضمين. تعرض لوحة النشاط ملخصات الاستدلال والخطط وحالة التنفيذ التي يوفرها CLI، متى توفرت.

### التحديثات التلقائية

1. يعرض **البحث عن تحديثات** رسالة «يتوفر تحديث» أو «أنت تستخدم أحدث إصدار». ولا ينزّل شيئًا أو يعيد التشغيل.
2. يعرض **تنزيل وتجهيز** رسالة «التحديث جاهز» عند اكتمال التحضير. ويمكنك مواصلة استخدام الإصدار الحالي.
3. لا يعيد **تحديث وإعادة تشغيل** التشغيل إلا بعد النقر عليه. بعد نجاح بدء الإصدار الجديد، تظهر رسالة «تم التحديث إلى vX.X.X» مرة واحدة. لا تظهر رسالة النجاح هذه عند التشغيل المعتاد أو الرجوع إلى إصدار سابق.

يتابع **البحث عن تحديثات** في الشريط الجانبي الإصدارات المستقرة المنشورة على [GitHub Releases](https://github.com/shixi-11/prism-desk/releases). ويعرض الإصدار المثبت والإصدار المتاح وملاحظات التغييرات قبل التنزيل. اختر **لاحقًا** لمواصلة استخدام إصدارك الحالي. لا تؤدي عمليات الإيداع العادية في فرع main إلى إشعارات تحديث. التحقق التلقائي مفعّل افتراضيًا: يتحقق Prism بعد بدء التشغيل وكل أربع ساعات. تشير نقطة زرقاء ثابتة بجوار «التحقق من وجود تحديثات» وأيقونة تحديث في الشريط العلوي إلى توفر إصدار. لا يؤدي التحقق إلى تنزيل التطبيق أو تثبيته أو إعادة تشغيله. اختر **تنزيل وتجهيز**، ثم **تحديث وإعادة تشغيل** في الوقت المناسب لك. تبقى النقطة حتى تصبح نسخة البرنامج المثبتة هي الأحدث. تُحفظ مسودات كل نافذة قبل إعادة التشغيل؛ وتمنع المهام والرسائل في قائمة الانتظار وعمليات الحسابات ومربعات حوار التحرير والمعاينات إعادة التشغيل إلى أن تنتهي أو تُغلق.

تحافظ التحديثات على إعدادات الحسابات ومخزن المهام ودليل بيانات المستخدم نفسها. وتظل نسخة المستودع الأصلية والتثبيت السابق متاحين. يترك فشل التنزيل أو البناء الإصدار قيد التشغيل سليمًا؛ وإذا تعذر على التطبيق الجديد إكمال بدء التشغيل، فإن فتح Prism مجددًا يستعيد الإصدار السابق. تمنع التغييرات المحلية في الشفرة المصدرية التحديثات، ويتطلب التحضير مساحة خالية لا تقل عن 2 GB. يجب أن يظل Git مثبتًا؛ ويتضمن بناء سطح المكتب بيئة تشغيل Node وnpm اللازمين لعمليات البناء المستقبلية. تحتاج التثبيتات التي تسبق آلية التحديث هذه إلى سحب يدوي وإعادة بناء مرة واحدة باستخدام أوامر التثبيت أعلاه.

### الإعداد

يمكن لمعظم المستخدمين توصيل الحسابات من **الحسابات → ربط حساب**. ملف الإعدادات أدناه بديل متقدم. احتفظ بنسخة احتياطية من أي ملف موجود قبل نسخ المثال.

```powershell
New-Item -ItemType Directory -Force .local
Copy-Item config.example.json .local/config.json
```

عدّل `.local/config.json` بما يناسب جهازك. يمكنك أيضًا تعيين `PRISM_CONFIG` إلى مسار مطلق لملف الإعدادات.

يبدو إعداد الحساب الواحد كما يلي. استبدل دليل تسجيل الدخول في المثال بدليلك، واختر نموذجًا متاحًا لحسابك. تؤدي إضافة مزيد من العناصر إلى `profiles` إلى إضافة حسابات تنفيذ أخرى.

```json
{
  "profiles": [
    {
      "id": "codex-personal-1",
      "provider": "Codex",
      "name": "Personal 1",
      "home": "C:/PrismAccounts/codex-personal-1",
      "executable": "codex.exe",
      "model": "gpt-5.6-sol",
      "write": true
    }
  ]
}
```

| الحقل | الغرض |
| --- | --- |
| `profiles` | حسابات التنفيذ: المعرّف والمزوّد واسم العرض ودليل تسجيل الدخول والملف التنفيذي والنموذج وصلاحية الكتابة |
| `storageRoot` | الموقع الدائم لسجلات المهام |
| `assistant.path` | دليل اختياري للمساعد يحتوي على `SKILL.md` |
| `assistant.instructions` | تعليمات اختيارية مشتركة بين المهام |
| `skillsPath` | دليل المهارات المشترك |
| `apps` | ربط أسماء التطبيقات بمسارات الملفات التنفيذية أو ملفات الدخول |

استخدم مسارات مطلقة للموارد المحلية ودليل تسجيل دخول منفصلًا لكل حساب. حافظ على ثبات معرّفات ملفات التعريف: تستخدمها المهام الموجودة للتعرف على الحسابات. تُعرَّف البنية الافتراضية لملفات التعريف في [electron/config.cjs](electron/config.cjs).

تُخزَّن المهام في دليل بيانات المستخدم الخاص بالتطبيق ما لم يُضبط `storageRoot`. تبقى بيانات اعتماد تسجيل الدخول في دليل المزوّد نفسه. تُستثنى الإعدادات المحلية وسجلات المهام وملفات السجل من Git.

### صلاحيات الملفات والأوامر

اختر **للقراءة فقط** أو **تعديل المشروع** أو **وصول كامل** في محرر الرسائل. يتوفر الوصول الكامل لـ Codex وClaude وGrok: ويتيح الوصول إلى ملفات خارج المشروع ويوافق تلقائيًا على تنفيذ الأدوات، ضمن صلاحيات نظام التشغيل. تُوضع التغييرات التي تُجرى أثناء التنفيذ في الانتظار لتطبيقها في التشغيل التالي. تعتمد التثبيتات الجديدة «تعديل المشروع» افتراضيًا للحسابات المدعومة. اختر **تعيين كصلاحية افتراضية للمهام الجديدة** لحفظ تفضيلك؛ وتحتفظ المهام الموجودة بصلاحياتها الخاصة. تظل موائمات القراءة فقط للقراءة فقط.

### الحسابات والأدوات المحلية

تدعم موائمات Codex وClaude وGrok مهام تعديل الملفات. يلتزم Grok بصلاحيات المهمة المحددة: يعطّل وضع القراءة فقط أدوات التحرير وأدوات Shell؛ ويستخدم «تعديل المشروع» ملف تعريف مساحة العمل في CLI وتأكيدات العمليات؛ ويتيح «وصول كامل» تنفيذ الأدوات. تظل ملفات التعريف الموجودة التي تتضمن `write: false` للقراءة فقط حتى تفعيل الكتابة صراحةً. تعتمد النماذج المتاحة على CLI المثبت والحساب المحدد.

تعرض لوحة حصة الاستخدام المعلومات التي يعيدها المزوّد. في فترات Grok الموحّدة الصالحة، يُفسَّر حذف قيمة الاستخدام الصفري وفق تفسير العميل الرسمي؛ وتظل الاستجابات الفارغة أو غير السليمة أو المنتهية الصلاحية مجهولة. تعيد استعلامات Claude المحاولة مرة واحدة بعد فشل اتصال عابر أو غياب استجابة الاستخدام، ولكنها لا تعيد المحاولة مطلقًا بعد فشل المصادقة. لا تؤدي أخطاء المصادقة أو الشبكة إلى تبديل الحساب كما لو أن الحصة قد نفدت. يتطلب التسليم التلقائي استجابة معروفة تدل على نفاد الحصة واكتمال التنفيذ السابق.

تُحجب عناوين البريد الإلكتروني للحسابات افتراضيًا؛ استخدم زر العين لإظهارها أو إخفائها. يبقى سجل الاستعلامات على هذا الجهاز. بعد إعادة التشغيل، تحتفظ السجلات بتاريخها ووقتها الأصليين وتُعلَّم على أنها بحاجة إلى تحديث. لا تمنح القراءات السابقة مطلقًا إذنًا بالتنفيذ أو باستخدام أرصدة إعادة التعيين.

لا يلجأ Prism إلى الفوترة بمفتاح API ولا يشتري أرصدة. يتطلب تنفيذ Claude وGrok التأكد من تعطيل الفوترة الإضافية. ويتطلب استخدام رصيد إعادة تعيين موجود في Codex تأكيدًا منفصلًا للحساب المحدد.

يمكن مشاركة ملفات المساعد والمهارات بين الحسابات. يجب إعداد صلاحيات MCP واتصالات التطبيقات لكل بيئة تنفيذ على حدة. يسرد اكتشاف التطبيقات نقاط الدخول المثبتة؛ ويفحص إجراء التحقق العمليات المدعومة بشكل منفصل.

### التطوير

```powershell
npm test
npm run build
npm run build:desktop
```

تستخدم اختبارات الوحدات بيانات حسابات اختبارية معزولة. تُشرح فحوص سطح المكتب وCLI الفعلية الاختيارية في [scripts/README.md](scripts/README.md)؛ وتتطلب الفحوص الفعلية حسابات اختبار وقد تستهلك من حصة الاشتراك.
