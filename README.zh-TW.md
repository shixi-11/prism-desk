**一個任務，持續向前。**

把 **Codex、Claude Code 和 Grok** 放進同一個 Windows 桌面工作台。集中管理訂閱帳號、專案檔案與對話，切換帳號後也能接著做下去。

如果你使用多種 AI 程式設計 CLI 來開發產品、設計網站或完成創作專案，Prism 能減少切換終端與重複說明背景的時間，讓你專注於眼前的工作。

### 為什麼使用 Prism？

- **切換帳號，延續工作。** 原始要求、對話、進度備註及已記錄的工具結果會隨同一任務交接，專案檔案留在原處。
- **一個專案，同時推進多件事。** 實作、審查與研究可分別開啟對話，即使共用同一工作目錄也能並行執行。
- **想到補充，隨時傳送。** Codex、Claude 或 Grok 工作時仍可追加要求，選擇即時引導或佇列；停止與核准各自作用於對應對話。

### 你可以做什麼

| 功能 | 實際用途 |
| --- | --- |
| 多對話並行 | 相同專案、相同或巢狀目錄中的不同對話均可同時執行；每個對話可獨立停止或接收補充要求。 |
| 執行中追加要求 | 向正在執行的 Codex、Claude 或 Grok 原生對話傳送補充訊息；CLI 可能在目前生成或工具步驟結束後處理。 |
| 接續同一個任務 | 將工作移交給另一個帳號時，一併保留原始要求、對話、進度筆記與已記錄的工具結果。 |
| 選擇執行帳號 | 選擇已設定的 Codex、Claude 或 Grok CLI 設定檔。每個設定檔使用獨立的登入目錄。可從帳號面板移除不再使用的帳號；任務歷程與本機登入資料夾仍會保留。 |
| 變更模型與推理設定 | 可在任務進行中調整任一設定。變更會套用至下一次執行，並在該任務內依帳號分別儲存。 |
| Codex Fast 模式 | 為支援的模型開啟更快回應，同時增加額度消耗。預設關閉，按任務內的帳號儲存，下次執行生效，不改變思考等級。 |
| 查詢額度 | 查看供應商回報的可用百分比、額度期間與重設時間。若回應提供相關資料，Codex 重置卡也會顯示各張到期日。 |
| 額度用盡後移交 | 啟用自動移交，或自行選擇下一個帳號。Prism 會等到上一次執行結束後才繼續。 |
| 使用本機技能與工具 | 指定助理指示、技能資料夾與已安裝的應用程式供 Prism 使用。查看偵測到的入口與支援的應用程式操作。 |
| 將工作保留在本機 | 選擇永久的任務儲存資料夾、新增進度筆記，並匯出 Markdown 對話記錄。 |
| 使用你的語言工作 | 從九種介面語言中選擇，包括由右至左顯示的阿拉伯文，並可切換淺色與深色沙漠佈景主題。 |

不同對話可以在相同或重疊的工作目錄內同時執行，包括具有寫入權限的對話；同一對話內的訊息仍依序執行。停止或引導只作用於對應對話，閒置對話選擇帳號後立即儲存為實際執行帳號。

右鍵專案可釘選、編輯名稱、選擇分區、建立永久 Git 工作樹、全部標為已讀、封存聊天或移除專案。移除專案保留檔案與會話，工作樹從目前 Git 提交建立。

### 安裝

以下指令會安裝穩定版本 **v0.1.29**。請查看[最新發布版本](https://github.com/shixi-11/prism-desk/releases/latest)，確認其版本與雙語變更說明。

你需要 Windows、Git、Node.js 22.12 或更新版本、npm，以及所選供應商的官方 CLI。請分別登入各個 CLI。

```powershell
git clone --branch v0.1.29 https://github.com/shixi-11/prism-desk.git
cd prism-desk
npm install
npm run build
npm run build:desktop
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-host.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1
```

建置指令碼會編譯 Windows 處理程序主機，以便一併停止 CLI 子處理程序。它使用 Windows 隨附的 .NET Framework 編譯器。

### 開始第一個任務之前

為每個要使用的供應商安裝官方 CLI，然後透過該 CLI 登入。僅登入網站或桌面應用程式，並不會完成 Prism 的設定。

- **Codex**：依照 [CLI 安裝指南](https://developers.openai.com/codex/cli/)操作，並使用你的 ChatGPT 帳號登入。
- **Claude**：安裝 [Claude Code](https://code.claude.com/docs/en/setup)，然後使用受支援的 Claude 訂閱[登入](https://code.claude.com/docs/en/authentication)。執行前檢查訂閱登入；額外用量設定不作為執行門檻。
- **Grok**：安裝官方 Grok CLI，並使用你的訂閱帳號登入。

開啟**帳號 → 連接帳號**，選擇 Codex、Claude 或 Grok，並為帳號命名。依序選擇**儲存並繼續 → 取得登入連結 → 複製登入連結**，即可開始官方 CLI 授權流程。將連結貼到瀏覽器的網址列。若 Claude 顯示授權碼，請將完整代碼貼到**授權碼**欄位，再選擇**提交授權碼**。代碼只會傳送給正在等候的官方 CLI，之後便會從輸入欄位清除。完成授權後，Prism 會驗證訂閱登入狀態，無須重新啟動即可使用該帳號。此頁面也支援檢查既有登入狀態、取消授權或再次複製連結、重新命名設定檔，以及停用或啟用帳號。停用帳號會保留過去的任務與憑證。進階設定可讓你選擇官方 CLI 執行檔，或匯入既有的獨立登入目錄；已建立的帳號目錄與平台身分無法變更。缺少 CLI 時，介面會提供官方安裝說明連結。未來新增的平台需要各自的供應商與執行介接器。

### 一般任務流程

1. 點擊**新增 → 新對話**並填寫名稱。工作目錄可留空，使用獨立、持久的工作區，也可以選擇已儲存的專案。**新增 → 新專案**支援建立資料夾或使用現有資料夾，現有檔案留在原處。空專案會保留在側欄；點擊專案旁的 **＋**，即可在該目錄新增對話。同一個專案可以容納多條對話。
2. 選擇執行帳號、模型與推理強度。檢閱時使用**唯讀**，編輯時使用**專案內編輯**。
3. 輸入要求，並以 **Ctrl + Enter** 傳送。工作進行時，可查看對話與執行記錄。
4. 將重要決策或待辦工作加入進度筆記。若要更換帳號，請選擇下一個帳號並使用移交控制項；必要時，先停止目前的執行。
5. 透過任務右鍵選單、按兩下任務名稱或按 **F2** 重新命名，按 **Enter** 儲存，或按 **Esc** 取消。
6. 在同一個任務中繼續工作。需要 Markdown 副本時可匯出記錄，或開啟任務儲存資料夾以尋找本機檔案。

下一個帳號會收到已儲存的對話、進度筆記與工具記錄。供應商內部的模型狀態不會移轉。

### 訊息、設定與預覽

#### 目標與計畫

輸入區上方的精簡**目標列**會顯示已儲存的目標、執行狀態與累計執行時間。你可以在目標列中編輯、暫停、繼續或刪除目標；展開後可查看完整目標、可編輯的計畫與執行詳情。暫停會停止目前的執行，並保留佇列中的訊息。刪除會等到執行停止後移除目標，並保留待處理訊息供你檢閱；對話記錄與工作區檔案仍可使用。計時器不計入暫停、閒置與應用程式關閉期間的時間。官方額度用盡會與網路或登入失敗分開顯示。

當你要求 Codex 設定或變更目標時，它可以透過 Prism 的原生工具儲存目標。其他入口可以提出目標，供你在介面中採用。聊天文字即使聲稱目標已儲存，也不會自行變更實際目標。**先制訂計畫**會以唯讀權限執行，並傳回草稿供你檢閱。當訊息僅用於討論待確認的計畫時，輸入區會明確標示；選擇**確認計畫並執行**後，才會以任務設定的權限開始實作。目標與計畫會跨工作階段保留，也會保存在移交記錄中。

#### 模型與移交

可以使用**切換並繼續**，在同一個帳號內套用模型變更。已確認的執行會記錄其帳號、模型與推理等級；僅儲存選擇不會顯示為已完成切換。**自動接續偏好**會開啟帳號清單，你可以拖曳調整順序，並設定每個帳號的模型與推理等級。變更會自動儲存至目前任務。清單會標示無法滿足任務寫入權限需求的帳號；移交時也會考量圖片支援能力。

#### 帳號與視窗

每張帳號卡片都有可編輯的**備註名**與鉛筆按鈕。這只會變更顯示名稱，不會變更登入身分。Codex 原生提問與受支援的問題及選項清單訊息，會提供可點選的選項與自訂回答。按下 Windows 標題列的 **×** 會將 Prism 隱藏至通知區域；使用系統匣選單中的**結束稜鏡**，即可停止進行中的工作並結束程式。

#### 任務整理

在任務上按滑鼠右鍵，即可重新命名、釘選、標示為未讀、封存、依專案或區段分組、分享、複製、建立分支、開啟資料夾或對話、開啟另一個視窗，或刪除任務。側邊欄中的**已封存與已刪除**可還原隱藏的任務。刪除任務會保留其工作區與對話檔案。選擇專案會變更後續工作的執行位置；既有檔案仍留在原始資料夾。建立分支會啟動全新的 CLI 工作階段，並複製對話附件；選擇獨立工作區時，會從空白資料夾開始。分享功能會預覽本機 Markdown 文件，供你複製或儲存；不會建立託管的公開連結。任務變更會在已開啟的視窗之間同步。

將未在執行的對話拖曳到另一個專案名稱上，即可變更工作目錄並保留歷史與草稿。原專案檔案留在原處，其他對話不會合併。

**Fast** 開關位於傳送按鈕旁。點擊棱鏡 Logo 可返回未選取對話的首頁，保留既有草稿與正在執行的工作。Claude 過程說明合併顯示，成功執行的最終答覆獨立保留。背景程序宿主不建立主控台視窗，同時發起的模型清單請求共用一次 CLI 查詢。

#### 檢視與額度

頂端列提供底部執行記錄與帳號側邊欄的顯示切換。這些狀態會儲存在本機。在「帳號」中，**一鍵查詢全部**會查詢每個已設定的設定檔，並顯示可用額度、重設時間、Codex 重置卡與卡片到期日。單一查詢失敗不會中止其餘帳號的查詢。

#### 圖片

貼上螢幕擷取畫面、將圖片拖放至輸入區，或使用圖片按鈕加入圖片（最多五張，每張 10 MB）。Codex 會接收本機圖片；Claude 通過訂閱檢查後，會接收原生圖片內容。Claude 圖片執行尚未使用已登入的帳號驗證。若 Grok CLI 宣告支援直接圖片內容，便會使用該方式；否則會透過原生 Read 工具開啟附加的圖片。此流程已使用登入訂閱帳號的環境驗證。

#### 訊息與草稿

執行中可繼續傳送，佇列訊息依序等候，也可取消。設定中可選擇 Enter 或 Ctrl/⌘+Enter 傳送，以及佇列或即時引導。Codex、Claude 和 Grok 均可向執行中的原生對話傳送補充要求；CLI 可能在目前生成或工具步驟結束後處理。未確認送達的訊息會保留等待核對。應用程式開啟期間，切換任務會保留各自的草稿。

#### 檔案預覽

開啟預覽面板或按一下檔案連結，即可查看圖片、PDF、Markdown、程式碼與文字。文字檔案可以編輯並儲存；儲存前會檢查外部變更。HTML 預覽可顯示獨立頁面；互動式專案則可使用其執行中的 HTTP 位址。部分網站會封鎖嵌入顯示。活動面板會在有相關資料時，顯示 CLI 提供的推理摘要、計畫與執行狀態。

正文或程式碼區塊中獨立成行的絕對路徑可點擊，包括含空格、中文的 Windows 路徑。資料夾連結可直接開啟檔案總管；本機檔案提供應用程式開啟或資料夾定位入口，影片等無法內嵌預覽的格式也可使用。執行檔和指令碼僅在資料夾中顯示。

### 自動更新

1. **檢查更新**會顯示「發現新版本」或「已是最新版本」。不會下載或重新啟動。
2. **下載並準備**會在準備完成後顯示「更新已準備好」。你可以繼續使用目前版本。
3. **更新並重新啟動**只有在你按下後才會重新啟動。新版本成功啟動後，會顯示一次「已升級至 vX.X.X」。一般啟動與回復舊版不會顯示此成功訊息。

側邊欄中的**檢查更新**以已發布的穩定版 [GitHub Releases](https://github.com/shixi-11/prism-desk/releases) 為依據。下載前會顯示已安裝版本、可用版本與變更說明。選擇**稍後**即可繼續使用目前版本。一般的 main 分支提交不會觸發更新通知。自動檢查預設啟用：Prism 會在啟動後及每隔四小時檢查一次。「檢查更新」旁持續顯示的藍點與頂端列的更新圖示，表示有可用版本。檢查不會下載、安裝或重新啟動應用程式。你可以在方便時選擇**下載並準備**，再選擇**更新並重新啟動**。藍點會持續顯示，直到已安裝的修訂版本更新至最新。重新啟動前會儲存每個視窗的草稿；任務、佇列訊息、帳號操作、編輯對話方塊與預覽，都會阻止重新啟動，直到完成或關閉。

更新會保留相同的帳號設定、任務儲存位置與使用者資料目錄。原始簽出目錄與先前安裝仍會保留。下載或建置失敗不會影響正在執行的版本；若新應用程式未能完成啟動，再次開啟 Prism 時會還原先前版本。本機原始碼變更會阻止更新，且準備更新至少需要 2 GB 可用空間。Git 必須保持安裝狀態；桌面建置包含未來建置所需的 Node 執行階段與 npm。早於此更新程式的安裝版本，需要使用上方安裝指令手動拉取並重新建置一次。

### 設定

多數使用者可以在**帳號 → 連接帳號**中連接帳號。下方設定檔是進階替代方式。複製範例前，請先備份既有檔案。

```powershell
New-Item -ItemType Directory -Force .local
Copy-Item config.example.json .local/config.json
```

依照你的電腦環境編輯 `.local/config.json`。你也可以將 `PRISM_CONFIG` 設為設定檔的絕對路徑。

單一帳號的設定如下。請將範例登入目錄換成你自己的目錄，並選擇該帳號可用的模型。在 `profiles` 中新增項目，即可增加執行帳號。

```json
{
  "profiles": [
    {
      "id": "codex-personal-1",
      "provider": "Codex",
      "name": "Personal 1",
      "home": "C:/PrismAccounts/codex-personal-1",
      "executable": "codex.exe",
      "model": "gpt-5.6-sol",
      "write": true
    }
  ]
}
```

| 欄位 | 用途 |
| --- | --- |
| `profiles` | 執行帳號：ID、供應商、顯示名稱、登入目錄、執行檔、模型與寫入權限 |
| `storageRoot` | 任務記錄的永久儲存位置 |
| `assistant.path` | 選填的助理目錄，內含 `SKILL.md` |
| `assistant.instructions` | 選填的跨任務共用指示 |
| `skillsPath` | 共用技能目錄 |
| `apps` | 應用程式名稱與執行檔或進入點檔案路徑的對應 |

本機資源請使用絕對路徑，並為每個帳號使用獨立的登入目錄。請保持設定檔 ID 不變：既有任務會使用這些 ID 識別帳號。預設設定檔結構定義於 [electron/config.cjs](electron/config.cjs)。

除非設定了 `storageRoot`，否則任務會儲存在應用程式的使用者資料目錄中。登入憑證保留在供應商自己的目錄。本機設定、任務記錄與日誌均排除於 Git 追蹤之外。

### 檔案與指令權限

在輸入區選擇**唯讀**、**專案內編輯**或**完整存取**。Codex、Claude 與 Grok 均支援完整存取權：在作業系統權限範圍內，允許存取專案外的檔案，並自動核准工具執行。執行期間做出的變更會排入佇列，於下一次執行套用。新安裝預設為支援的帳號使用「編輯專案」。選擇**設為新任務預設權限**可儲存偏好；既有任務保留各自的權限。唯讀介接器仍維持唯讀。

### 帳號與本機工具

Codex、Claude 與 Grok 介接器支援檔案編輯任務。Grok 會遵循所選的任務權限：唯讀會停用編輯與 Shell 工具；「編輯專案」使用 CLI 工作區設定檔與操作確認；「完整存取權」允許工具執行。既有設定檔若設為 `write: false`，在明確啟用前仍維持唯讀。可用模型取決於已安裝的 CLI 與所選帳號。

額度面板顯示供應商回傳的資訊。對於有效的 Grok 統一額度期間，若省略了用量為零的資料，會依官方用戶端的解讀處理；空白、格式錯誤或已過期的回應仍顯示為未知。Claude 查詢遇到暫時性連線失敗或缺少用量回應時，會重試一次，但驗證失敗後絕不重試。驗證或網路錯誤不會被當作額度用盡而觸發帳號切換。自動移交需要可辨識的額度用盡回應，且上一次執行已完成。

帳號電子郵件地址預設會遮蔽；可使用眼睛按鈕顯示或隱藏。查詢歷程保留在此裝置上。重新啟動後，記錄會保留原始日期與時間，並標示為需要重新整理。歷史查詢值絕不會用來授權執行或使用重置卡。

Prism 不會退回 API Key 計費，也不購買額度。額度查詢不攔截執行，額外用量提示已移除；實際可用性與計費依平台帳號設定處理。使用既有 Codex 重置卡仍須針對該帳號單獨確認，不中斷正在執行的會話，也不自動重新啟動已結束的執行。

圓形傳送箭頭在目前任務執行時切換為停止按鈕；追加內容仍可引導或排隊，不加入語音控制項。

助理檔案與技能可以跨帳號共用。MCP 權限與應用程式連線必須在每個執行環境中分別設定。應用程式探索會列出已安裝的進入點；驗證操作會另外檢查支援的操作。

開啟**共享能力**，選擇**檢查共享能力 → 同步本機最新**，對照上次同步紀錄檢查本機技能入口檔案和路徑。系統技能與新增的目錄會在同步後進入共享索引。點擊**接入本機已安裝外掛**，可按本機 Codex 的正式安裝清單批量登記外掛並接入可讀技能資料，同時開啟**自動同步已安裝外掛資料**；可在**來源與接入**中關閉。啟動、返回視窗或每五分鐘檢查一次；停用、解除安裝及手動排除的外掛不會自動補回。原檔案保留在來源位置，下一輪任務按需讀取共享索引。

已安裝外掛清單使用實際安裝版本，不以快取中的較新版本替代。僅快取的外掛可單獨顯示，不進入批量接入；安裝狀態檢查失敗時保留上次清單，並停止自動接入。登記外掛和讀取技能資料不代表工具已可用或已授權，介面單獨顯示連線狀態。Codex 的 MCP 連線仍需在帳號獨立 CLI 中設定與驗證；Claude、Grok、Gemini 目前執行通道未開放外部 MCP。綁定原桌面應用程式的工具標為暫不支援。同步資料不會複製登入憑證、API 金鑰或自動啟用工具權限。
